# TOPIK 한국 APK

1. Zipni oching va ichidagi fayllarni GitHub repo'ga yuklang (.github papkasi repo ildizida bo'lishi shart).
2. Repo -> Settings -> Actions -> General -> Workflow permissions -> "Read and write permissions" -> Save.
3. Actions -> "Build APK" -> Run workflow (yoki main branchga push qiling).
4. Tugagach, repo asosiy sahifasida o'ng tomondagi **Releases** dan TOPIK.apk ni to'g'ridan-to'g'ri yuklab oling
   (yoki run ichidagi "topik-apk" artifactidan).
